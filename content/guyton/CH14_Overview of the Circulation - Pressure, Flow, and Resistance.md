## 章節導讀

循環系統的功能在於滿足身體各組織的需求：輸送養分、移除代謝廢物、攜帶激素，以及維持細胞赖以生存的組織液環境。本章建立理解循環生理的三大基本原則：<span style="color:#60a5fa">血流</span>由區域需求控制，心輸出量是各組織<span style="color:#60a5fa">血流</span>的總和，<span style="color:#60a5fa">血壓</span>調節與局部<span style="color:#60a5fa">血流</span>控制及心輸出量控制相互獨立。讀者將學習血液在血管系統中的壓力分布（全身上下各段血管的<span style="color:#60a5fa">血壓</span>數值）、<span style="color:#60a5fa">血流</span>的基本物理原理（Ohm 定律、Poiseuille 定律）、<span style="color:#60a5fa">血流</span>的兩種流態（<span style="color:#60a5fa">層流</span>與<span style="color:#60a5fa">湍流</span>）、<span style="color:#e2e8f0">血液黏度</span>與 hematocrit 的關係，以及血管<span style="color:#60a5fa">阻力</span>在串聯與並聯電路中的計算方式。這些概念是理解後續章節中<span style="color:#60a5fa">血壓</span>調控與組織<span style="color:#60a5fa">血流</span>控制的基礎。

## 循環系統的組成與血量分布

### 循環的兩大分支

循環分為<span style="color:#22d3ee">體循環</span>（systemic circulation）與<span style="color:#22d3ee">肺循環</span>（pulmonary circulation）。<span style="color:#22d3ee">體循環</span>（又稱 greater 或 peripheral circulation）負責將血液送往全身各組織。

### 各段血管的血量分布

全身血量<span style="color:#34d399">約 5 公升</span>，分布如下：

| 區域 | 占總血量百分比 |
|------|-------------|
| <span style="color:#22d3ee">體循環</span><span style="color:#22d3ee">靜脈</span>系統 | ~64% |
| 心臟 | 7% |
| 肺血管 | 9% |
| <span style="color:#22d3ee">體循環</span>动脉系統 | ~13% |
| 小动脉與<span style="color:#22d3ee">微血管</span> | ~7% |

值得注意的是，<span style="color:#22d3ee">微血管</span>（capillary）血量極低，但這正是血液與組織間物質交換最關鍵的場所。

### 各段血管的截面積與<span style="color:#60a5fa">血流</span>速度

<span style="color:#60a5fa">血流</span>速度與血管截面積成反比（連續性方程式：v = F/A）。<span style="color:#22d3ee">微血管</span>的總截面積約為主動员的 1000 倍，故<span style="color:#60a5fa">血流</span>速度在<span style="color:#22d3ee">微血管</span>中僅約 0.3 mm/sec。<span style="color:#60a5fa">血流</span>在<span style="color:#22d3ee">微血管</span>中停留時間虽仅 1-3 秒，但已完成所有必要的物質擴散交換。

## 各段血管的<span style="color:#60a5fa">血壓</span>

<span style="color:#22d3ee">體循環</span>中，<span style="color:#60a5fa">血壓</span>由主動员平均 10<span style="color:#34d399">0 mm Hg</span> 逐漸下降至腔<span style="color:#22d3ee">靜脈</span>入口處的 <span style="color:#34d399">0 mm Hg</span>。<span style="color:#22d3ee">肺循環</span>的<span style="color:#60a5fa">血壓</span>遠低於<span style="color:#22d3ee">體循環</span>，因為<span style="color:#22d3ee">肺循環</span>的唯一需求是使血液在肺<span style="color:#22d3ee">微血管</span>中進行氣體交換。

| 位置 | <span style="color:#60a5fa">血壓</span>（mm Hg） |
|------|-------------|
| 主動员（平均） | 100 |
| 主動员（收縮壓/舒張壓） | 120/80 |
| 小动脉 | 50-70 |
| <span style="color:#22d3ee">微血管</span>（平均值） | 17（範圍 10-35） |
| 中心<span style="color:#22d3ee">靜脈</span>（右心房） | 0 |
| 肺动脉（平均） | 16 |
| 肺<span style="color:#22d3ee">微血管</span>（平均） | 7 |

## <span style="color:#60a5fa">血流</span>與壓力的基本關係

### Ohm 定律

<span style="color:#60a5fa">血流</span>量由驅動壓力差（ΔP）與<span style="color:#60a5fa">阻力</span>（R）決定：

$$F = \Delta P / R$$

或寫成 ΔP = F × R 和 R = ΔP / F。意即：<span style="color:#60a5fa">血流</span>量與壓力差成正比，與<span style="color:#60a5fa">阻力</span>成反比。重要的是，決定<span style="color:#60a5fa">血流</span>的是兩端壓力差而非絕對壓力。

### <span style="color:#60a5fa">層流</span>與<span style="color:#60a5fa">湍流</span>

**<span style="color:#60a5fa">層流</span>（Laminar flow / streamline flow）**：<span style="color:#60a5fa">血流</span>呈同心圓層次，中心流速最快，靠近管壁的液<span style="color:#60a5fa">層流</span>速最慢，形成拋物線速度分布。<span style="color:#60a5fa">層流</span>時摩擦<span style="color:#60a5fa">阻力</span>最小。

**<span style="color:#60a5fa">湍流</span>（Turbulent flow）**：<span style="color:#60a5fa">血流</span>出現橫向流動與漩渦（eddy currents），<span style="color:#60a5fa">阻力</span>大增。雷諾茲數（Reynolds number, Re）是判斷<span style="color:#60a5fa">湍流</span>傾向的指標：

$$Re = \rho v d / \eta$$

其中 ρ 為血液密度，v 為流速，d 為血管直徑，η 為黏度。Re 超過約 2000 時，多數血管即發生<span style="color:#60a5fa">湍流</span>。

大動员中 Re 可達數千，造成主動员與肺动员根部始終有輕度<span style="color:#60a5fa">湍流</span>；小血管中 Re 極低，不會發生<span style="color:#60a5fa">湍流</span>。

## 血管<span style="color:#60a5fa">阻力</span>

### <span style="color:#60a5fa">阻力</span>單位

若兩點間壓力差為 1 mm Hg 且流量為 1 ml/sec，<span style="color:#60a5fa">阻力</span>即為 1 peripheral resistance unit（PRU）。

### 總周邊<span style="color:#60a5fa">阻力</span>與肺血管<span style="color:#60a5fa">阻力</span>

心輸出量（正常約 100 ml/sec）為全身總<span style="color:#60a5fa">血流</span>量。主動员與腔<span style="color:#22d3ee">靜脈</span>間平均壓力差<span style="color:#34d399">約 10<span style="color:#34d399">0 mm Hg</span></span>，故：

- **總周邊<span style="color:#60a5fa">阻力</span>** ≈ 100/100 = 1 PRU
- **肺血管總<span style="color:#60a5fa">阻力</span>** ≈ 14/100 ≈ 0.14 PRU（約為<span style="color:#22d3ee">體循環</span>的 1/7）

### 血管徑向對<span style="color:#60a5fa">阻力</span>的影響——Poiseuille 定律

$$F = \frac{\Delta P \cdot \pi r^4}{8 \eta L}$$

<span style="color:#60a5fa">血流</span>量與半徑的四次方（r⁴）成正比。直徑增加 2 倍，<span style="color:#60a5fa">血流</span>量增加 16 倍。這就是為什麼微动员（arteriole）口徑些微變化即可造成<span style="color:#60a5fa">血流</span>巨大改變。

### 串聯與並聯血管

**串聯（Series）**：<span style="color:#60a5fa">血流</span>依次通過动员、<span style="color:#22d3ee">微血管</span>、<span style="color:#22d3ee">靜脈</span>，總<span style="color:#60a5fa">阻力</span>為各段<span style="color:#60a5fa">阻力</span>之和：R_total = R_1 + R_2 + R_3 + ...

**並聯（Parallel）**：各組織的血管以並聯方式排列，總<span style="color:#60a5fa">阻力</span>倒數為各並聯路徑<span style="color:#60a5fa">阻力</span>倒數之和：1/R_total = 1/R_1 + 1/R_2 + 1/R_3 + ...

並聯血管的總<span style="color:#60a5fa">阻力</span>遠小於任何單一血管的<span style="color:#60a5fa">阻力</span>。

## <span style="color:#e2e8f0">血液黏度</span>與 Hematocrit

<span style="color:#e2e8f0">血液黏度</span>約為水的 3-4 倍，主要由<span style="color:#e2e8f0">紅血球</span>數量決定。

**Hematocrit**：指血漿中<span style="color:#e2e8f0">紅血球</span>所佔的體積百分比。成年男性平均約 42%，女性約 38%。Hematocrit 升高時<span style="color:#e2e8f0">血液黏度</span>急劇上升，可達水的 10 倍，使<span style="color:#60a5fa">血流</span><span style="color:#60a5fa">阻力</span>大增。

## <span style="color:#60a5fa">血壓</span>對<span style="color:#60a5fa">血流</span>的影響與<span style="color:#60a5fa">自身調節</span>

### <span style="color:#60a5fa">自身調節</span>（Autoregulation）

<span style="color:#60a5fa">血壓</span>升高時，組織<span style="color:#60a5fa">血流</span>的增加遠小於預期，因為局部控制機制在數秒內啟動，使微动員收縮而增加<span style="color:#60a5fa">阻力</span>。多數組織在<span style="color:#60a5fa">血壓</span> 70-175 mm Hg 範圍內，<span style="color:#60a5fa">血流</span>可維持相對恆定。此機制包括：

- **代謝理論**：<span style="color:#60a5fa">血流</span>過多沖走組織中的血管擴張物質，使血管收縮。
- **肌源性理論（Myogenic theory）**：血管壁被伸展時，平滑肌反射性收縮。

### Laplace 定律

$$T = \Delta P \times \frac{r}{h}$$

管徑越大、承受壓力越高的血管（如主動员）需要越厚的管壁來抵禦張力。<span style="color:#22d3ee">微血管</span>口徑極小，即使承受 65-7<span style="color:#34d399">0 mm Hg</span> 的壓力也不至於破裂。
