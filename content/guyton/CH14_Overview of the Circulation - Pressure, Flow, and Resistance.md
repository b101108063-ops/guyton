UNIT IV THE CIRCULATION

## 章節導讀

循環系統的功能在於滿足身體各組織的需求：輸送養分、移除代謝廢物、攜帶激素，以及維持細胞赖以生存的組織液環境。本章建立理解循環生理的三大基本原則：血流由區域需求控制、心輸出量是各組織血流的總和、血壓調節與局部血流控制及心輸出量控制相互獨立。讀者將學習血液在血管系統中的壓力分布（全身上下各段血管的血壓數值）、血流的基本物理原理（Ohm定律、Poiseuille定律）、血流的兩種流態（laminar flow與turbulent flow）、血液黏度與hematocrit的關係，以及血管阻力在串聯與並聯電路中的計算方式。這些概念是理解後續章節中血壓調控與組織血流控制的基礎。

## 循環系統的組成與血量分布

### 循環的兩大分支

循環分為**體循環（systemic circulation）**與**肺循環（pulmonary circulation）**。體循環（又稱greater或peripheral circulation）負責將血液送往全身各組織。

### 各段血管的血量分布

全身血量分布如下（全血量約5公升）：

| 區域 | 占總血量百分比 |
|------|-------------|
| 體循環（總計） | 84% |
| 心臟與肺 | 16% |
| 體循環中：靜脈 | ~64% |
| 體循環中：动脉 | ~13% |
| 體循環中：小动脉與微血管 | ~7% |
| 心臟 | 7% |
| 肺血管 | 9% |

值得注意的是，**微血管（capillary）血量極低**，但這正是血液與組織間物質交換最關鍵的場所。

### 各段血管的截面積與血流速度

血流速度與血管截面積成反比（連續性方程式：v = F/A）。

| 血管 | 截面積（cm²） |
|------|-------------|
| 主動脈 | 2.5 |
| 小动脉 | 20 |
| 微血管 | 2500 |
| 靜脈（小+大） | 330 |
| 腔靜脈 | 8 |

微血管的總截面積約為主動脈的1000倍，故血流速度在微血管中僅約0.3 mm/sec。血流在微血管中停留時間虽仅1–3秒，但已完成所有必要的物質擴散交換。

## 各段血管的血壓

圖14-2顯示血壓在循環系統中的分布：

| 位置 | 血壓（mm Hg） |
|------|-------------|
| 主動脈（平均） | 100 |
| 主動脈（收縮壓/舒張壓） | 120/80 |
| 小动脉 | 50–70 |
| 微血管（平均值） | 17（範圍10–35） |
| 中心靜脈（右心房） | 0 |
| 肺动脉（平均） | 16 |
| 肺微血管（平均） | 7 |

體循環中，血壓由主動脈的平均100 mm Hg逐漸下降至腔靜脈入口處的0 mm Hg。肺循環的血壓遠低於體循環，因為肺循環的唯一需求是使血液在肺微血管中進行氣體交換。

## 血流與壓力的基本關係

### Ohm定律

血流量由**驅動壓力差（ΔP）**與**阻力（R）**決定：

$$F = \Delta P / R$$

或寫成：

$$\Delta P = F \times R$$
$$R = \Delta P / F$$

意即：血流量與壓力差成正比，與阻力成反比。重要的是，決定血流的是**兩端壓力差**而非絕對壓力。

### 血液流量的測定

- **電磁流量計（Electromagnetic flowmeter）**：利用導電液體通過磁場產生電壓的原理（圖14-4）。可記錄毫秒級的血流變化，包括搏動性血流。
- **都卜勒超聲波流量計（Ultrasonic Doppler flowmeter）**：發射超聲波，利用紅血球反射波的頻率偏移（Doppler effect）計算血流速度（圖14-5）。

### 層流與湍流

**層流（Laminar flow / streamline flow）**：血流呈同心圓層次，中心流速最快，靠近管壁的液層流速最慢，形成拋物線速度分布（圖14-6A、B）。層流時摩擦阻力最小。

**湍流（Turbulent flow）**：血流出現橫向流動與漩渦（eddy currents），阻力大增。雷諾茲數（Reynolds number, Re）是判斷湍流傾向的指標：

$$Re = \rho v d / \eta$$

其中ρ為血液密度，v為流速，d為血管直徑，η為黏度。Re超過約2000時，多數血管即發生湍流。

大动脉中Re可達數千，造成主動脉與肺动脉根部始終有輕度湍流；小血管中Re極低，不會發生湍流。

## 血管阻力

### 阻力單位

若兩點間壓力差為1 mm Hg且流量為1 ml/sec，阻力即為1 peripheral resistance unit（PRU）。

### 總周邊阻力與肺血管阻力

心輸出量（正常約100 ml/sec）為全身總血流量。主動脉與腔靜脈間平均壓力差約100 mm Hg，故：

- **總周邊阻力** ≈ 100/100 = 1 PRU（範圍0.2–4 PRU）
- **肺血管總阻力** ≈ 14/100 ≈ 0.14 PRU（ 約為體循環的1/7）

### 血管徑向對阻力的影響——Poiseuille定律

$$F = \frac{\Delta P \cdot \pi r^4}{8 \eta L}$$

血流量與**半徑的四次方（r⁴）**成正比。直徑增加2倍，血流量增加16倍；直徑增加4倍，血流量增加256倍（圖14-8）。這就是為什麼微动脉（arteriole）口徑些微變化即可造成血流巨大改變。

### 串聯與並聯血管

**串聯（Series）**：血流依次通過动脉、微血管、靜脈，總阻力為各段阻力之和：

$$R_{total} = R_1 + R_2 + R_3 + ...$$

**並聯（Parallel）**：各組織的血管以並聯方式排列，總阻力倒數為各並聯路徑阻力倒數之和：

$$\frac{1}{R_{total}} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + ...$$

並聯血管的總阻力遠小於任何單一血管的阻力。切除一個器官（如截肢）會移除一條並聯路徑，使總阻力增加、總血流量減少。

## 血液黏度與Hematocrit

血液黏度約為水的3–4倍，主要由紅血球數量決定。

**Hematocrit**：指血漿中紅血球所佔的體積百分比。成年男性平均約42%，女性約38%。Hematocrit升高時血液黏度急劇上升（圖14-11），可達水的10倍，使血流阻力大增。

白蛋白、球蛋白等血漿蛋白對黏度的影響相對較小（血漿黏度約為水的1.5倍）。

## 血壓對血流的影響與自身調節

### 自身調節（Autoregulation）

血壓升高時，組織血流的增加遠小於預期，因為局部控制機制在數秒內啟動，使微动脉收縮而增加阻力；反之亦然。多數組織在血壓70–175 mm Hg範圍內，血流可維持相對恆定（圖14-12）。此機制稱為**autoregulation**，包括：

- **代謝理論**：血流過多沖走組織中的血管擴張物質，使血管收縮。
- **肌源性理論（Myogenic theory）**：血管壁被伸展時，平滑肌反射性收縮（圖14-3）。

### 被動性血流-壓力關係

在缺乏autoregulation的離體標本中，血壓升高不僅增加驅動壓力，也同時擴張彈性血管、降低阻力，使血流的增加超過Ohm定律的預期。當血壓降至临界关閉壓（critical closing pressure）以下時，血流停止。

### 血管壁張力與剪切力

根據Laplace定律：

$$T = \Delta P \times \frac{r}{h}$$

管徑越大、承受壓力越高的血管（如主動脉）需要越厚的管壁來抵禦張力。微血管口徑極小，即使承受65–70 mm Hg的壓力也不至於破裂。

血流產生的**剪切力（shear stress）**作用於血管內皮細胞，與血流速度、血液黏度成正比，與半徑的立方成反比。內皮細胞將剪切力訊號轉化為血管結構與口徑的適應性變化（見第17章）。
