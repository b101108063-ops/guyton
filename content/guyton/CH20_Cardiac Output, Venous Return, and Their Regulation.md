## 章節導讀

Cardiac output（<span style="color:#60a5fa">心輸出量</span>）是循環系統的核心指標，代表心臟每分鐘泵出的血液量，約等於<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>量的總和。本章系統性地說明三個相互關聯的主題：第一，正常成年人在休息狀態下 cardiac output 約為 5 L/min，以及什麼因素決定了這個基礎值；第二，<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>（venous return）如何受到血液體積與分佈、<span style="color:#22d3ee">靜脈</span>張力與心臟功能的影響；第三，<span style="color:#60a5fa">心輸出量</span>的神經與內分泌調控機制，特別是<span style="color:#e2e8f0">交感神經</span>對心率與<span style="color:#60a5fa">心肌收縮力</span>的影響，以及 baroreceptor reflex 如何維持<span style="color:#60a5fa">心輸出量</span>的穩定。本章介紹的 Guyton 圖解法（cardiac output curve 與 venous return curve 的交點分析），是理解心衰竭、休克與運動時循環變化的基礎工具。

## Cardiac Output（<span style="color:#60a5fa">心輸出量</span>）的定義與正常值

Cardiac output（CO）是心臟每分鐘泵出的血液體積，計算公式為：

**CO = Heart Rate（HR）× Stroke Volume（SV）**

正常成年男性靜止時，HR <span style="color:#34d399">約 70 次/分</span>，SV <span style="color:#34d399">約 70 ml/次</span>，CO <span style="color:#34d399">約 5 L/min</span>。女性平均值略低。Cardiac output 會隨身體需求而大幅變化——運動時可達靜止時的 4–7 倍。

Fick principle 提供了測量 CO 的經典方法：測量肺部氧氣消耗量與混合<span style="color:#22d3ee">靜脈</span>血與动脉血的氧含量差值，計算公式為：

**CO = Oxygen consumption / (Arterial O₂ content − Venous O₂ content)**

另一個常用方法是使用 indocyanine green dye 或 temperature稀释法測量。

## Determinants of Cardiac Output（<span style="color:#60a5fa">心輸出量</span>的決定因素）

<span style="color:#60a5fa">心輸出量</span>由心臟本身的功能與外週迴路兩個面向共同決定，這也是 Guyton 圖解法的核心概念：

### 心臟因素：Cardiac Output Curve（<span style="color:#60a5fa">心輸出量</span>曲線）

Cardiac output curve 描述的是：在不同的 right atrial pressure（<span style="color:#22d3ee">右心房</span>壓）下，心臟能夠輸出的血液量。當 right atrial pressure 適當時（正常約 <span style="color:#34d399">0 mm Hg</span>），輸出量最高；當<span style="color:#22d3ee">右心房</span>壓過高（如心衰竭）時，輸出量下降。

<span style="color:#60a5fa">心輸出量</span>曲線受以下因素影響：
- **<span style="color:#e2e8f0">交感神經</span>刺激**：升高 HR 與 SV，曲線向上向左移動
- **副<span style="color:#e2e8f0">交感神經</span>刺激**：降低 HR，曲線向下移動
- **<span style="color:#60a5fa">心肌收縮力</span>**：增強時 SV 增加，曲線變陡
- **<span style="color:#60a5fa">後負荷</span>（afterload）**：<span style="color:#22d3ee">主動脈</span>壓力升高時，SV 減少，曲線下降

### 外週因素：Venous Return Curve（<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線）

Venous return curve 描述的是：在不同的 right atrial pressure 下，從組織回流至心臟的血液量。正常情況下，當<span style="color:#22d3ee">右心房</span>壓為 <span style="color:#34d399">0 mm Hg</span> 時，<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>總量等於<span style="color:#60a5fa">心輸出量</span>（ steady state）。

Venous return curve 的斜率與位置受以下因素影響：
- **血液體積**：增加 blood volume 使曲線向右移動（需要更高的<span style="color:#22d3ee">右心房</span>壓來維持相同的回流）
- **<span style="color:#22d3ee">靜脈</span>張力（venous tone）**：<span style="color:#e2e8f0">交感神經</span>刺激<span style="color:#22d3ee">靜脈</span>收縮，使血液回流加速，曲線向上移動
- **全身血管阻力**：增加時使曲線斜率變小（回流減少）

### Guyton Analysis：交點決定 steady-state Cardiac Output

在正常<span style="color:#e2e8f0">穩態</span>下，<span style="color:#60a5fa">心輸出量</span>等於<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>量。將<span style="color:#60a5fa">心輸出量</span>曲線與<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線繪製在同一坐標圖上，其交點即為實際的 cardiac output 與 right atrial pressure。

例如，<span style="color:#e2e8f0">交感神經</span>興奮會同時：① 提升<span style="color:#60a5fa">心輸出量</span>曲線（心臟幫浦更強）和 ② 提升<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線（<span style="color:#22d3ee">靜脈</span>收縮使血液回流增加）。兩個效應共同使交點向右上方移動，CO 增加；反之，休克或失血時，交感活化將兩條曲線推向極端，以維持重要器官灌流。

## Regulation of Cardiac Output（<span style="color:#60a5fa">心輸出量</span>的調控）

### 心率的調控

影響心率的主要因素包括：

1. **副<span style="color:#e2e8f0">交感神經</span>（Vagus nerve）**：正常休息時，副交感活性佔優勢，使竇房結（SA node）放電頻率維持在 60–80 次/分。阻斷副交感（給予 atropine）後，心率會升至 100–120 次/分，顯示副交感基礎張力的抑制效應。

2. **<span style="color:#e2e8f0">交感神經</span>**：運動、情緒或出血時，交感活性增強，直接刺激 SA node 與房室結（AV node），大幅提升心率。交感效應透過 β₁-adrenergic receptors 達成，可被 propranolol 等 β-blocker 阻斷。

3. **體液因子**：Epinephrine 與 norepinephrine（來自 adrenal medulla）與<span style="color:#e2e8f0">交感神經</span>共同作用；甲狀腺素增加竇房結對 catecholamines 的敏感性；電解質（尤其是鉀與鈣）異常也會影響心率。

### <span style="color:#60a5fa">每搏輸出量</span>（Stroke Volume）的調控

Stroke volume 的決定因素可分為三類：

1. **<span style="color:#60a5fa">前負荷</span>（Preload）**：心肌纖維在收縮前的伸展程度，受 end-diastolic volume（EDV）影響。Frank-Starling mechanism 說明：EDV 增加時，心肌初長增加，收縮力增強，SV 上升。這是維持左右<span style="color:#60a5fa">心輸出量</span>匹配的主要機制。

2. **<span style="color:#60a5fa">心肌收縮力</span>（Myocardial contractility）**：由交感刺激、體內兒茶酚胺濃度與鈣離子濃度決定。Contractility 增加時，相同 preload 下可產生更大的收縮力，射出更多血液。

3. **<span style="color:#60a5fa">後負荷</span>（Afterload）**：心室在收縮時必須克服的阻力，主要由<span style="color:#22d3ee">主動脈</span>壓力與大血管順應度決定。Afterload 增加時，SV 下降；這在心衰竭與 hypertension 患者中格外重要。

## Venous Return（<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>）與其調控

<span style="color:#22d3ee">靜脈</span>系統是血液的儲存庫，容納了約 60% 的全身血液量。<span style="color:#22d3ee">靜脈</span>張力的微小變化，即可動員大量血液進入心臟，瞬間改變 cardiac output。

### 影響<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>的主要因素

1. **血液體積與分佈**：站立時，下肢<span style="color:#22d3ee">靜脈</span>承受 hydrostatic pressure，血液傾向積滯在下肢；同時<span style="color:#e2e8f0">交感神經</span>反射性地收縮<span style="color:#22d3ee">靜脈</span>，維持<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>。失血時，<span style="color:#e2e8f0">交感神經</span>強烈活化，<span style="color:#22d3ee">靜脈</span>收縮以彌補血液不足。

2. **呼吸運動（Respiratory pump）**：吸氣時胸腔內壓下降，<span style="color:#22d3ee">右心房</span>壓降低，促進<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>；呼氣時效應逆轉。在正常呼吸週期中，這種泵動效應協助血液從周邊流回心臟。

3. **心臟泵功能（Cardiac pump）**：心室收縮時，血液被推向<span style="color:#22d3ee">主動脈</span>與肺动脉；心舒張期時，心室內壓下降，幫助血液從心房進入心室。良好的心臟泵功能是維持足夠<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>的關鍵。

4. **肌肉幫浦（Muscle pump）**：骨骼肌收縮時，會擠壓<span style="color:#22d3ee">靜脈</span>並推動血液向心臟方向流動；<span style="color:#22d3ee">靜脈</span>瓣膜確保血液單向流動。長時間站立時，肌肉幫浦功能不足可能導致血液積滯與暈厥。

## Integration of Cardiac Output and Venous Return（<span style="color:#60a5fa">心輸出量</span>與<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>的整合）

Guyton 的圖解分析提供了一個整合性的框架，來理解<span style="color:#60a5fa">心輸出量</span>與<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>如何共同決定循環<span style="color:#e2e8f0">穩態</span>：

- **<span style="color:#60a5fa">心輸出量</span>曲線**代表心臟的幫浦能力（pump function）
- **<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線**代表外週循環的血液回流特性（peripheral flow characteristics）
- 兩條曲線的交點，決定了實際的 cardiac output、stroke volume 與 right atrial pressure

這個框架可應用於：
- **運動**：交感活化使兩條曲線皆向上移動，CO 增加
- **心衰竭**：<span style="color:#60a5fa">心輸出量</span>曲線下降，如果<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線不變，交點向左下移動，CO ↓，right atrial pressure ↑
- **失血性休克**：<span style="color:#60a5fa"><span style="color:#22d3ee">靜脈</span>回流</span>曲線向右移動（血液體積減少），同時<span style="color:#60a5fa">心輸出量</span>曲線因交感補償向上移動，CO 最初可能維持，但最終若未改善，會陷入惡性循環
