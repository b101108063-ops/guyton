## 心臟衰竭的病理生理學

當心輸出量不足以滿足身體組織的代謝需求時，就會發生<span class="c-red">心臟衰竭</span>。

心臟衰竭可以分為：

- **左心衰竭**：左心室泵血功能障礙
- **右心衰竭**：右心室泵血功能障礙
- **全心衰竭**：兩側心室都受影響

## 心輸出量減少的代償反應

當心輸出量下降時，身體會啟動多種代償機制來維持組織灌注：

### 交感神經系統激活

心輸出量減少立即激活<span class="c-yellow">交感神經系統</span>：

| 效應 | 結果 |
|------|------|
| 心率增加 | 心輸出量↑ |
| 心肌收縮力增加 | 每搏輸出量↑ |
| 靜脈收縮 | 中心靜脈壓↑ → 前負荷↑ |
| 動脈收縮 | 維持血壓 |

這些代償反應在急性心力衰竭中特別重要。

### 腎臟反應和液體瀦留

心輸出量減少導致腎臟灌注減少，引發：

1. <span class="c-yellow">腎素-血管緊張素-醛固酮系統（RAAS）</span>激活
2. 鈉和水瀦留
3. 細胞外液量增加
4. 循環血量增加

### Frank-Starling機制

根據<span class="c-cyan">Frank-Starling機制</span>，心臟前負荷增加（在一定範圍內）會導致心肌纖維拉長，增加心臟收縮力。

這種代償可以暫時改善心輸出量。

然而，如果前負荷增加過度：
- 左心衰竭時肺靜脈壓升高
- 導致<span class="c-red">肺水腫</span>
- 呼吸困難和缺氧

## 冠狀循環的基本特性

心臟是唯一在整個心跳週期都能從冠狀动脉获得血流供應的器官。

### 冠狀血流特點

| 特性 | 數值 |
|------|------|
| 冠狀血流（安靜時） | 約250 ml/min |
| 佔心輸出量百分比 | 約5% |
| 左心室心肌耗氧量 | 約25%全身耗氧量 |

### 冠狀血流調節

冠狀血流主要受以下因素調節：

- **心肌代謝需求**：最重要的調節因素
- **自動調節**：在一定血壓範圍內維持恆定血流
- **神經因素**：交感神經增加血流，副交感神經減少血流

### 冠狀血流特異性

心內膜下心肌（尤其是左心室）在收縮期承受最高壓力，因此：

- 收縮期時這些區域的血流幾乎為零
- 主要在舒張期灌注
- 這使心內膜下心肌對缺血最敏感

## 心肌功能障礙的影響

### 心室功能障礙

當心肌受損或功能障礙時：

1. **泵血功能下降**：每搏輸出量和心輸出量減少
2. **舒張功能障礙**：心室順應性降低，充盈受阻
3. **心室擴大**：慢性情況下心室逐漸擴大

### 心室功能曲線

正常心室功能曲線：
- X軸：LVEDP（左心室舒張末期壓）
- Y軸：心輸出量或每搏作功

在心臟衰竭時：
- 曲線向右下移動
- 相同LVEDP下心輸出量降低

## 急性與慢性心臟衰竭

### 急性心臟衰竭

急性發作，代償機制來不及充分啟動：

- 突然心輸出量減少
- 血壓可能下降
- 需要立即醫療干預

### 慢性心臟衰竭

逐漸進展，代償機制持續激活：

- 心肌肥厚
- 神經內分泌持續激活
- 逐漸惡化

#### 慢性心臟衰竭的神經內分泌惡性循環

```
心輸出量減少
    ↓
交感神經激活 + RAAS激活
    ↓
心率↑ + 血管收縮 + 鈉水瀦留
    ↓
心臟前負荷↑ + 後負荷↑
    ↓
心臟工作負擔↑ → 心肌進一步受損
    ↓
心輸出量進一步減少（惡性循環）
```

## 心臟衰竭分類

### NYHA心功能分級

| 分級 | 描述 |
|------|------|
| I級 | 日常活動不引起症狀 |
| II級 | 輕度活動引起症狀 |
| III級 | 明顯活動引起症狀 |
| IV級 | 休息時也有症狀 |

## 治療原則

心臟衰竭的治療目標：

1. **減少心臟工作負擔**
   - 臥床休息
   - 血管擴張劑

2. **改善心臟泵血功能**
   - 正性肌力藥物（如毛地黃）
   - 利尿劑（減少前負荷）

3. **阻斷有害的神經內分泌激活**
   - ACE抑制劑
   - β受體阻斷劑
   - 醛固酮拮抗劑
