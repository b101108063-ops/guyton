## 章節導讀

<span style="color:#60a5fa">心衰竭</span>（<span style="color:#60a5fa">cardiac failure</span>）是<span style="color:#22d3ee">心臟</span>幫浦功能受損、無法維持足夠組織灌流的臨床症候群。本章分三個層次說明：第一，<span style="color:#60a5fa">左心衰竭</span>（<span style="color:#60a5fa">left-sided failure</span>）與<span style="color:#60a5fa">右心衰竭</span>（<span style="color:#60a5fa">right-sided failure</span>）各自的病理生理學；第二，心衰竭時<span style="color:#60a5fa">心輸出量</span>（<span style="color:#60a5fa">cardiac output</span>）下降所引發的代償機制——包括 <span style="color:#60a5fa">Frank-Starling compensation</span>、<span style="color:#60a5fa">交感神經</span>活化、與 <span style="color:#fb923c">renin-angiotensin-aldosterone system</span> 的啟動；第三，這些代償機制在長期反覆啟動後，如何走向惡性循環而加速心衰竭的惡化（稱為<span style="color:#60a5fa">心臟重塑</span>，<span style="color:#60a5fa">cardiac remodeling</span>）。理解心衰竭的代償與失代償之間的平衡，是掌握臨床上心衰竭治療原則（<span style="color:#fb923c">利尿劑</span>、<span style="color:#fb923c">血管張力素轉化酶抑制劑</span>、<span style="color:#fb923c">β受體阻斷劑</span>等）的生理學基礎。

## 定義與分類

心衰竭指的是心臟無法泵出足夠血液以滿足組織代謝需求的狀態，可依以下方式分類：

- **<span style="color:#60a5fa">左心衰竭</span>（<span style="color:#60a5fa">left-sided failure</span>）**：<span style="color:#22d3ee">左心室</span>泵血功能受損，血液滯留於肺部
- **<span style="color:#60a5fa">右心衰竭</span>（<span style="color:#60a5fa">right-sided failure</span>）**：<span style="color:#22d3ee">右心室</span>功能受損，血液滯留於全身靜脈系統
- **<span style="color:#60a5fa">收縮功能障礙</span>（<span style="color:#60a5fa">systolic dysfunction</span>）**：<span style="color:#22d3ee">心肌</span>收縮力下降，常見於 <span style="color:#c084fc">myocardial infarction</span> 後
- **<span style="color:#60a5fa">舒張功能障礙</span>（<span style="color:#60a5fa">diastolic dysfunction</span>）**：<span style="color:#22d3ee">心室</span>順應度下降，充盈受阻

兩者常同時存在（全心衰竭），且皆導致相同的核心問題：心輸出量下降與器官灌流不足。

## 左心衰竭的主要表現

左心衰竭時，左心室無法有效地將血液泵入主動脈，導致：

1. **肺靜脈壓力升高** → 肺部毛細血管壓力上升 → 液體滲出至<span style="color:#22d3ee">肺間質</span> → **<span style="color:#f87171">pulmonary edema</span>（肺水腫）**
2. **<span style="color:#60a5fa">呼吸困難</span>（<span style="color:#60a5fa">dyspnea</span>）**：尤其在運動或平躺時加劇，因為這些姿勢增加靜脈回流
3. **<span style="color:#60a5fa">心輸出量</span>下降** → <span style="color:#22d3ee">腎臟</span>灌流減少 → 鈉與水分滯留 → 進一步增加血液體積，加重<span style="color:#60a5fa">心衰竭</span>

圖 22-2 說明了左心衰竭時 pulmonary edema 的發生機制：肺毛細血管壓力慢性升高 → 毛細血管與肺泡之間的液體交換失衡 → 液體積聚於肺泡周圍 → 氣體交換受阻。

## 右心衰竭的主要表現

右心衰竭時，右心室無法有效接收來自全身靜脈的血液，導致：

1. **全身靜脈與毛細血管壓力升高** → 液體滲出至組織間隙 → **<span style="color:#f87171">peripheral edema</span>（周邊水腫）**
2. **<span style="color:#22d3ee">肝臟</span>充血（<span style="color:#22d3ee">hepatic congestion</span>）** → <span style="color:#22d3ee">肝功能</span>受損與黃疸
3. **<span style="color:#60a5fa">頸靜脈怒張</span>（<span style="color:#60a5fa">jugular venous distension</span>）**
4. **<span style="color:#f87171">腹水</span>（<span style="color:#f87171">ascites</span>）**：腹腔毛細血管壓力升高，液體滲出

右心衰竭最常由左心衰竭引起（左心衰竭導致肺高壓，長期使右心室負荷過重）；也可由肺部疾病（cor pulmonale）或肺栓塞直接引起。

## 心輸出量下降的代償機制

當心輸出量減少時，身體會啟動多重代償機制，試圖維持 arterial pressure 與重要器官灌流：

### Frank-Starling 機制

<span style="color:#60a5fa">心輸出量</span>減少 → <span style="color:#22d3ee">左心室</span> <span style="color:#60a5fa">end-diastolic volume</span>（<span style="color:#60a5fa">EDV</span>）增加 → <span style="color:#22d3ee">心肌</span>纖維被拉長 → <span style="color:#60a5fa">Frank-Starling mechanism</span> 啟動 → 在一定範圍內，<span style="color:#22d3ee">心肌</span>收縮力增強，試圖恢復輸出量。然而，當<span style="color:#22d3ee">心肌</span>過度拉伸（<span style="color:#60a5fa">EDV</span> 過大）時，收縮力反而下降，走向失代償。

### 交感神經系統的活化

<span style="color:#60a5fa">Cardiac output</span> 下降 → <span style="color:#60a5fa">arterial pressure</span> 降低 → <span style="color:#60a5fa">baroreceptor reflex</span> 啟動 → 全身<span style="color:#60a5fa">交感神經</span>活化：

- <span style="color:#22d3ee">心臟</span>：<span style="color:#60a5fa">心率</span>加快與<span style="color:#22d3ee">心肌</span>收縮力增強
- 血管：全身血管收縮（除了<span style="color:#22d3ee">腦</span>與<span style="color:#22d3ee">心臟</span>），維持<span style="color:#60a5fa">血壓</span>
- <span style="color:#22d3ee">腎臟</span>：腎血管收縮，減少水鈉排泄

這些作用在短期內有助於維持灌流，但長期交感過度活化會導致心肌壞損、血管結構重塑與心律不整。

### Renin-Angiotensin-Aldosterone System（RAAS）的活化

<span style="color:#60a5fa">心輸出量</span>下降 → <span style="color:#22d3ee">腎臟</span>灌流減少 → <span style="color:#22d3ee">juxtaglomerular cells</span> 釋放 <span style="color:#fb923c">renin</span> → <span style="color:#fb923c">angiotensin I</span> → <span style="color:#fb923c">angiotensin II</span> → 造成血管收縮與 <span style="color:#fb923c">aldosterone</span> 分泌增加。<span style="color:#fb923c">Aldosterone</span> 作用於<span style="color:#22d3ee">腎小管</span>，促進鈉與水分的再吸收，擴張血液體積。

然而，長期 RAAS 活化對心衰竭是有害的：

- <span style="color:#fb923c">Angiotensin II</span> 直接促進<span style="color:#22d3ee">心肌</span>纖維化與<span style="color:#22d3ee">心室</span>重塑
- <span style="color:#fb923c">Aldosterone</span> 導致<span style="color:#22d3ee">心肌</span>纖維化與電生理不穩定性
- 鈉水分滯留使<span style="color:#60a5fa">心衰竭</span>惡化

這也是臨床上使用 ACE inhibitors 與 aldosterone antagonists 治療心衰竭的生理學基礎。

### ADH（血管加壓素）的釋放

血容量減少與<span style="color:#60a5fa">血漿滲透壓</span>升高會刺激<span style="color:#22d3ee">posterior pituitary</span> 釋放 <span style="color:#fb923c">ADH</span>，促進<span style="color:#22d3ee">腎小管</span>對水的再吸收，進一步增加血液體積。雖然短期有助於維持血壓，但過多的水滯留會加重肺水腫。

## 心臟重塑（Cardiac Remodeling）與失代償

代償機制在短期內可維持循環穩態，但長期過度活化會導致心室結構與功能的進行性病變：

- **<span style="color:#60a5fa">心室肥厚</span>（<span style="color:#60a5fa">Ventricular hypertrophy</span>）**：面對過高的後負荷或容量負荷，<span style="color:#22d3ee">心肌</span>纖維增粗以增加收縮力，但同時降低順應度，導致<span style="color:#60a5fa">舒張功能障礙</span>
- **<span style="color:#60a5fa">心肌纖維化</span>（<span style="color:#60a5fa">Fibrosis</span>）**：<span style="color:#fb923c">Angiotensin II</span> 與 <span style="color:#fb923c">Aldosterone</span> 促進間質膠原蛋白沉積，降低<span style="color:#22d3ee">心肌</span>彈性
- **<span style="color:#60a5fa">心肌細胞凋亡</span>（<span style="color:#60a5fa">Apoptosis</span>）**：慢性缺血與<span style="color:#fb923c">兒茶酚胺</span>毒性可導致<span style="color:#22d3ee">心肌</span>細胞死亡

當這些結構性病變進展至一定程度時，Frank-Starling 機制失效，交感與 RAAS 代償亦不足，病人進入失代償狀態：cardiac output 持續下降、周邊水腫與肺水腫惡化、低血壓與器官灌流不足。

## 臨床上心衰竭的主要藥物治療原則

| 藥物類別 | 主要作用 | 治療效益 |
|----------|----------|----------|
| <span style="color:#fb923c">利尿劑</span>（Diuretics） | 增加鈉與水分排泄 | 減少血液體積，改善<span style="color:#f87171">肺水腫</span>與<span style="color:#f87171">周邊水腫</span> |
| <span style="color:#fb923c">ACE Inhibitors</span> / ARBs | 阻斷 <span style="color:#fb923c">angiotensin II</span> 的生成或作用 | 減少血管收縮與<span style="color:#22d3ee">心肌</span>纖維化，改善重塑 |
| <span style="color:#fb923c">β-受體阻斷劑</span>（β-Blockers） | 抑制<span style="color:#60a5fa">交感活性</span> | 降低<span style="color:#60a5fa">心率</span>與<span style="color:#22d3ee">心肌</span>氧耗，長期改善<span style="color:#22d3ee">心室</span>功能 |
| <span style="color:#fb923c">Aldosterone antagonists</span> | 阻斷 <span style="color:#fb923c">aldosterone</span> 的鈉滯留作用 | 減少纖維化與水腫 |
| <span style="color:#fb923c">強心劑</span>（Digitalis） | 增加<span style="color:#22d3ee">心肌</span>收縮力 | 改善<span style="color:#60a5fa">心輸出量</span>與症狀 |
