## 腎上腺皮質的結構與激素

### 皮質的三層結構

腎上腺皮質可分為三層：

| 層次 | 區域 | 主要激素 |
|------|------|----------|
| 球狀帶 | 最外層 | 醛固酮（礦物皮質激素） |
| 束狀帶 | 中層 | 皮質醇（糖皮質激素） |
| 網狀帶 | 最內層 | 雄激素（脫氫表雄酮、雄烯二酮） |

### 皮質醇的化學與分泌

皮質醇是一種類固醇激素，由膽固醇經一系列酶反應合成。

正常情況下，成人每日分泌皮質醇約15-25 mg。

皮質醇的分泌具有晝夜節律：清晨（約6-8點）達到高峰，夜間最低。

皮質醇的分泌受下視丘-腦下垂體-腎上腺軸（HPA軸）調節。

## 皮質醇的代謝作用

### 對碳水化合物代謝的影響

皮質醇是維持血糖濃度的重要激素：

- 促進肝臟葡萄糖新生（刺激胺基酸轉化為葡萄糖）
- 抑制骨骼肌對葡萄糖的攝取與利用
- 促進肝糖分解
- 減少葡萄糖儲存為肝糖

這些作用使皮質醇成為對抗低血糖的重要激素。

### 對蛋白質代謝的影響

皮質醇促進肌肉蛋白質分解，釋放胺基酸進入血液。

這些胺基酸可供肝臟進行葡萄糖新生。

長期皮質醇過多會導致肌肉萎縮與軟弱。

### 對脂肪代謝的影響

皮質醇促進脂肪組織的脂肪分解。

然而，脂肪的分布會受到皮質醇的特異性影響，導致中心性肥胖（軀幹與腹部脂肪堆積）。

## 皮質醇的抗發炎與免疫抑制作用

### 抗發炎機制

皮質醇透過多種機制發揮強大的抗發炎作用：

- 抑制磷脂酶A2，減少花生四烯酸釋放與前列腺素合成
- 抑制環氧合酶（COX-2）表現
- 減少促發炎細胞激素（IL-1、IL-2、TNF-α）的產生
- 穩定嗜中性白血球的溶酶體膜
- 減少嗜酸性白血球與嗜鹼性白血球的數量

### 免疫抑制作用

皮質醇抑制免疫系統的多个環節：

- 減少淋巴細胞（尤其是T細胞）的增殖
- 抑制自然殺手細胞的活性
- 減少抗體產生
- 抑制巨噬細胞的抗原呈現

## 皮質醇與壓力反應

### 壓力激活HPA軸

身體或心理壓力會刺激下視丘釋放CRH（促腎上腺皮質激素釋放激素）。

CRH刺激腦下垂體分泌ACTH（促腎上腺皮質激素）。

ACTH刺激腎上腺皮質分泌皮質醇。

### 皮質醇在壓力時的作用

皮質醇在壓力反應中發揮重要作用：

- 提供能量以應對威脅
- 維持血壓與心血管功能
- 調節發炎與免疫反應
- 增強認知功能與警覺性

長期壓力導致皮質醇持續升高，可能對海馬迴造成損害，影響記憶功能。

## 醛固酮的生理作用

### 對腎臟鈉離子與鉀離子交換的影響

醛固酮主要作用於腎臟的集合管主細胞。

醛固酮的作用包括：

- 增加鈉離子通道（ENaC）的表現與活性
- 促進鈉離子主動回收
- 間接促進鉀離子分泌
- 刺激氫離子排泄

鈉離子回收伴隨水分回收，因此醛固酮也影響細胞外液容量與血壓。

### 醛固酮分泌的調節

| 刺激因素 | 機制 |
|----------|------|
| 血管張力素II | 直接刺激球狀帶細胞 |
| 血鉀濃度升高 | 直接刺激球狀帶細胞 |
| ACTH | 輕度刺激 |

### 腎素-血管張力素-醛固酮系統（RAAS）

當腎臟血流減少（例如低血壓、出血、鈉離子缺乏）時，腎絲球旁細胞會釋放腎素。

腎素將血管張力素原轉化為血管張力素I。

肺部的血管張力素轉化酶（ACE）將血管張力素I轉化為血管張力素II。

血管張力素II是強力的血管收縮劑，並刺激醛固酮分泌。

## 腎上腺皮質功能障礙

### 庫欣氏症候群

庫欣氏症候群是由皮質醇過多引起的疾病。

常見原因包括：

- 長期使用糖皮質激素藥物（最常見）
- 腦下垂體ACTH分泌過多（庫欣病）
- 腎上腺皮質腫瘤
- 異位ACTH腫瘤（如肺癌）

### 庫欣氏症候群的臨床表現

| 表現 | 說明 |
|------|------|
| 中心性肥胖 | 腹部與軀幹脂肪堆積，四肢纖細 |
| 月亮臉 | 臉部圓潤、雙下巴 |
| 水牛肩 | 頸背部脂肪墊 |
| 紫紋 | 腹部與大腿紫紅色皮膚紋路 |
| 高血壓 | 鈉離子回收增加 |
| 血糖升高 | 葡萄糖新生增加 |
| 骨質疏鬆 | 骨吸收增加 |
| 免疫抑制 | 感染風險增加 |
| 肌肉無力 | 蛋白質異化作用 |

### 腎上腺機能不全

腎上腺機能不全是皮質醇缺乏的狀態。

原因可分為：

- 原發性（愛迪生氏病）：腎上腺皮質直接受損
- 次發性：腦下垂體或下視丘功能障礙導致ACTH缺乏

### 愛迪生氏病的臨床特徵

- 皮膚色素沉著（由於ACTH與黑色素刺激素升高）
- 低血壓
- 鈉離子流失與高血鉀
- 倦怠與體重減輕
- 危及生命的腎上腺危機（休克、低血糖）

### 原發性醛固酮過多症（Conn氏症候群）

特徵：

- 高血壓
- 低血鉀（導致肌肉無力、心律不整）
- 代謝性鹼中毒
- 血漿醛固酮濃度升高
- 血漿腎素活性受抑制

## 腎上腺雄激素

### 去氫表雄酮（DHEA）

DHEA是體內最豐富的循環類固醇激素。

DHEA可在多種組織中轉化為更強力的雄激素或雌激素。

### 雄激素的生理作用

腎上腺雄激素的作用包括：

- 刺激青春期陰毛與腋毛生長
- 在停經後協助維持雄激素濃度
- 可能影響女性的性慾

## 糖皮質激素與礦物皮質激素比較

| 特性 | 皮質醇（糖皮質激素） | 醛固酮（礦物皮質激素） |
|------|---------------------|----------------------|
| 分泌來源 | 皮質束狀帶 | 皮質球狀帶 |
| 主要調節因子 | ACTH | 血管張力素II、血鉀 |
| 主要作用 | 調節代謝、抗發炎、免疫抑制 | 調節鈉鉀平衡、血壓 |
| 對血糖的影響 | 升高血糖 | 無直接作用 |
| 對血鉀的影響 | 輕度降低 | 顯著降低 |
| 對血鈉的影響 | 輕度增加 | 顯著增加 |
| 受體分布 | 全身各組織 | 腎臟為主 |
