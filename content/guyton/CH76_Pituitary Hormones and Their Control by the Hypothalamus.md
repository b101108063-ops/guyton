## 章節導讀

腦下垂體（<span style="color:#22d3ee">pituitary</span> gland）分為前葉（anterior <span style="color:#22d3ee">pituitary</span>）與後葉（posterior <span style="color:#22d3ee">pituitary</span>），兩者的解剖與功能截然不同。前葉沒有神經直接支配，而是經由 hypothalamic-hypophysial portal system 接收下丘腦釋放的激素（releasing/inhibitory hormones）來控制本身的激素分泌。下丘腦神經元合成的激素經軸突送至 median eminence，進入門脈系統後直接調控前葉細胞。相對地，後葉本身沒有腺體細胞，而是儲存並釋放由下丘腦視上核（supraoptic nucleus）與副視核（paraventricular nucleus）神經元軸突直接送來的神經肽（<span style="color:#fb923c">ADH</span> 與 <span style="color:#60a5fa">oxytocin</span>）。本章介紹前葉六種主要激素的功能與分泌調控，並詳細說明 growth hormone（<span style="color:#fb923c">GH</span>）的多重代謝效應、骨骼生長機制，以及缺乏或過量時的臨床表現。<span style="color:#fb923c">GH</span> 的分泌呈現脈衝式節律，受 <span style="color:#fb923c">GH</span>RH 與 somatostatin 双重調控，並透過胰島素樣生長因子（IGF-1/Somatomedin）發揮大部分生長效應。

## 下丘腦-垂體門脈系統

前葉是高度血管化的腺體，幾乎所有流經竇狀隙的血液都先經過下丘腦下部的毛細血管床，再經下丘腦-垂體門脈進入前葉（Figure 76-4）。

## Growth Hormone 的生理功能

除了 <span style="color:#fb923c">GH</span> 之外，多數前葉激素主要經由刺激下游靶腺（甲狀腺、腎上腺皮質、性腺、乳腺）來發揮作用。<span style="color:#fb923c">GH</span> 則直接作用於幾乎全身所有組織。

### 促進生長

<span style="color:#fb923c">GH</span> 是含 191 個胺基酸的蛋白質，使幾乎所有身體組織增大。它促進細胞增大與有絲分裂，增加細胞數量並使特定細胞（如骨細胞與早期肌肉細胞）進一步分化。

### 蛋白質代謝效應

<span style="color:#fb923c">GH</span> 促進蛋白質沉積，機制包括：

1. **促進胺基酸跨膜運輸**：<span style="color:#fb923c">GH</span> 直接增強多數胺基酸進入細胞，提高細胞內胺基酸濃度，是蛋白質合成的基礎之一。
2. **促進 RNA 轉譯**：即使細胞內胺基酸濃度未升高，<span style="color:#fb923c">GH</span> 仍增加核糖體的 RNA 轉譯，促進蛋白質合成。
3. **促進 DNA 轉錄**：24–48 小時後，<span style="color:#fb923c">GH</span> 也刺激細胞核 DNA 轉錄，形成更多 RNA，促進生長（這可能是 <span style="color:#fb923c">GH</span> 最主要的功能）。
4. **減少蛋白質分解**：<span style="color:#fb923c">GH</span> 動員游離脂肪酸後，脂肪酸成為細胞主要能源，發揮「蛋白質節約」效應。

### 脂肪利用效應

<span style="color:#fb923c">GH</span> 促使脂肪組織釋放脂肪酸進入血液，並促進細胞將脂肪酸轉化為 acetyl-CoA 供能。在 <span style="color:#fb923c">GH</span> 作用下，脂肪優先被用作能源而非 carbohydrate 與蛋白質，這有助於增加肌肉量。但 <span style="color:#fb923c">GH</span> 過量時動員脂肪過度可導致酮症與脂肪肝。

### 碳水化合物代謝效應

<span style="color:#fb923c">GH</span> 減少組織對葡萄糖的利用（胰島素阻抗效應），機制包括：
- 減少 GLUT4 轉位至細胞膜，降低骨骼肌與脂肪細胞對葡萄糖的攝取
- 增加肝臟葡萄糖新生
- 促使胰島素分泌（代償性）

這些效應被稱為 <span style="color:#fb923c">GH</span> 的「致糖尿病效應」（diabetogenic effect）。但是，<span style="color:#fb923c">GH</span> 分泌過量者（如 acromegaly 患者）通常偏瘦，與 type 2 diabetes 的肥胖表型不同。

**<span style="color:#fb923c">GH</span> 的生長效應需要胰島素與碳水化合物存在**：缺乏胰島素或完全排除碳水化合物時，<span style="color:#fb923c">GH</span> 無法促進生長。

## <span style="color:#fb923c">GH</span> 對軟骨與骨骼生長的作用

<span style="color:#fb923c">GH</span> 對骨骼的生長效應最為明顯，透過：

1. **軟骨內骨化（Endochondral ossification）**：<span style="color:#fb923c">GH</span> 刺激 epiphyseal cartilage（骺軟骨）增生，軟骨細胞先增殖，隨後被骨質取代，使骨長度增加。當骺軟骨與骨幹融合（late adolescence）後，骨長度便無法再增加。
2. **膜內骨化（Intramembranous ossification）**與骨膜增厚：<span style="color:#fb923c">GH</span> 活化 osteoblast，使膜性骨（如顱骨、下頜骨）的厚度增加，甚至在成年後仍可持續。

---

## <span style="color:#fb923c">GH</span> 透過胰島素樣生長因子（IGF-1）發揮作用

<span style="color:#fb923c">GH</span> 使肝臟（以及較少程度的其他組織）合成稱為胰島素樣生長因子（IGF，又稱 somatomedin）的蛋白質。IGF-1（Somatomedin C，分子量約 7500）是最主要的形式，血漿濃度與 <span style="color:#fb923c">GH</span> 分泌率密切相關。

IGF-1 缺陷的個體即使 <span style="color:#fb923c">GH</span> 分泌正常或偏高，仍無法正常生長（非洲小人症、Laron dwarfism 即為例證）。然而，<span style="color:#fb923c">GH</span> 也能直接作用於軟骨（不依賴 IGF-1）。

<span style="color:#fb923c">GH</span> 的半衰期不到 20 分鐘，但 IGF-1 與血漿攜帶蛋白結合後半衰期約 20 小時，使 <span style="color:#fb923c">GH</span> 脈衝式分泌的生長效應得以延續。

## <span style="color:#fb923c">GH</span> 分泌的調控

<span style="color:#fb923c">GH</span> 分泌呈現脈衝式節律，在睡眠後期的 Stage 3–4 NREM sleep 時分泌量最大。影響 <span style="color:#fb923c">GH</span> 分泌的因素包括：

| 刺激 <span style="color:#fb923c">GH</span> 分泌 | 抑制 <span style="color:#fb923c">GH</span> 分泌 |
|---|---|
| 禁食（尤其是蛋白質缺乏）| 肥胖 |
| 低血糖 | 高血糖 |
| 運動 | 衰老 |
| 興奮、創傷 | 甲狀腺機能低下 |
| Ghrelin（胃分泌的飢餓激素）| 甲狀腺機能亢進 |
| 特定胺基酸（如arginine）| 皮質醇過量 |

### <span style="color:#fb923c">GH</span>RH 與 Somatostatin 的雙重控制

<span style="color:#fb923c">GH</span>RH（44 胺基酸）由 arcuate nucleus 與 ventromedial nucleus 的神經元分泌；Somatostatin（14 胺基酸）由 periventricular nucleus 神經元分泌。<span style="color:#fb923c">GH</span>RH 透過 Gs 蛋白-cAMP 途徑刺激 <span style="color:#fb923c">GH</span> 分泌（短期促進 Ca²⁺ 內流，長期促進基因轉錄與新 <span style="color:#fb923c">GH</span> 合成）；Somatostatin 則抑制 <span style="color:#fb923c">GH</span> 分泌。

<span style="color:#fb923c">GH</span> 本身也有 negative feedback：直接抑制 <span style="color:#fb923c">GH</span>RH 或刺激 somatostatin 分泌。

## <span style="color:#fb923c">GH</span> 分泌異常

### 垂體功能低下症（Panhypopituitarism）

**成人**：症狀包括甲狀腺機能低下、腎上腺皮質機能低下、性腺機能減退。給予甲狀腺與腎上腺皮質激素可滿意控制。

**兒童——垂體性侏儒症**：身體各部比例正常但發育遲緩，智力正常。不經治療的兒童外觀如 10 歲只有 4–5 歲的身體發育，20 歲時只有 7–10 歲的發育。純 <span style="color:#fb923c">GH</span> 缺乏者約有三分之一可正常發育並生殖。現已可使用重組 DNA 技術合成的 h<span style="color:#fb923c">GH</span> 完全治愈此類侏儒症。

### 巨人症（Gigantism）

發病於青春期前（骺軟骨未融合），<span style="color:#fb923c">GH</span> 過量使身高異常增加，可達 8 英尺。約 10% 最終發展為糖尿病。治療：手術切除腫瘤或放射治療。

### 肢端肥大症（Acromegaly）

發病於青春期後（骺軟骨已融合），無法再長高，但骨骼與軟組織持續增厚。手腳變大、下頜前突、顱骨增大、舌頭與內臟（肝、腎）變大。出現 kyphosis（駝背）。治療同巨人症。

## <span style="color:#fb923c">GH</span> 與衰老

失去 <span style="color:#fb923c">GH</span> 分泌能力者會加速某些衰老特徵：皮膚皺紋增加、組織蛋白質沉積減少、脂肪堆積增加。血漿 <span style="color:#fb923c">GH</span> 濃度隨年齡下降，這可能是年老時身體組成與組織功能變化的原因之一。
